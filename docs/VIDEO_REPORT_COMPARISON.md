## 本轮修正

1. 报告顺序恢复为：摘要 -> 四类分布 -> 颜色热力 -> 六组属性 -> 商品明细 -> 机会结论 -> 锚点总览 -> 改款方案 -> 依据表 -> 三条策略。
2. 自有的价格/竞争诊断保留，但移动到视频主流程之后，明确标记为“行业增强附录”。
3. 报告容器最大宽度提升到 1880px，桌面左右边距缩至 12px；报告标题、章节、表格、分析阶段字号和行高同步增大。
4. 月购买量缺失时展示真实评论数；上架日期缺失时展示真实 BSR 或当前在售信号；颜色展示真实变体数和颜色名，不再形成连续空字段。
5. 方案按领口、袖型、面料、版型、设计元素、花纹图案轮转生成，并强制方向、ASIN、图片三重去重。
